# Aurora Quick Start Guide

## Installation
1. Install Fabric Loader for Minecraft 1.21.4
2. Install Fabric API 0.119.2+
3. Place aurora-1.0.0.jar in your mods folder
4. Launch Minecraft

## First Time Setup
1. Start a creative mode world
2. Press **Left Alt** to see the feature toolbar
3. Use **Left Alt + Numbers** to toggle features

## Essential Features for Building

### Recommended Setup for Large Builds
1. Enable **ExtendedReach** (Alt+1) - Reach blocks from 100 blocks away
2. Enable **NoClip** (Alt+1) - Fly through blocks
3. Enable **FlySpeed** (Alt+3) - Move 5x faster
4. Enable **FullBright** (Alt+10) - See everything clearly
5. Enable **FastPlace** (Alt+5) - Place blocks instantly
6. Enable **FastBreak** (Alt+6) - Break blocks instantly

### For Precision Work
- Enable **Tinker** (Key: L) - Cycle block states with empty hand
- Enable **Replace** (Key: R) - Replace blocks without breaking

### For Redstone Building  
- Enable **FreezeUpdates** (Alt+11) - Freeze block updates while working

## Feature Categories

### Movement (Cyan in HUD)
- NoClip - Phase through blocks
- ExtendedReach - Reach from 100 blocks
- FlySpeed - Fly 5x faster  
- NoFallDamage - No fall damage

### Building (Green in HUD)
- FastPlace - Instant block placement
- FastBreak - Instant block breaking
- ForcePlace - Place anywhere
- Replace - Replace blocks directly
- Tinker - Cycle block states

### Utilities (Yellow in HUD)
- FullBright - Night vision
- FreezeUpdates - Stop block updates

## Commands
```
/aurora list              # See all features
/aurora toggle fastbreak  # Toggle a feature
/aurora enable noclip     # Enable a feature
/aurora disable replace   # Disable a feature
```

## Tips & Tricks

1. **Combine NoClip + FlySpeed** for ultra-fast navigation through terrain
2. **Use ExtendedReach** to build tall structures without scaffolding
3. **Enable FullBright** when building underground
4. **FreezeUpdates** prevents redstone from firing while you build
5. **Replace** is perfect for swapping materials in large builds
6. **Tinker** with L key cycles stairs, slabs, fences quickly

## Troubleshooting

**Features not working?**
- Make sure you're in Creative mode
- Check if the feature is enabled (should be green in toolbar)
- Try toggling it off and on again

**Can't see the GUI?**
- Hold Left Alt to open the toolbar
- Check top-left for active features list

**Reach not working?**
- ExtendedReach mixin may need updating for your MC version
- Use NoClip + FlySpeed as alternative for now

## Building Tips

### Terrain Sculpting
1. Enable NoClip + ExtendedReach
2. Fly to viewing position
3. Use FastBreak to quickly remove blocks
4. Use FastPlace to fill in areas

### Large Structure Copying
1. Enable ExtendedReach (100 blocks)
2. Stand at center point
3. Work on entire structure without moving
4. Use FlySpeed to reposition quickly

### Underground Bases
1. FullBright for visibility
2. NoClip to navigate caves
3. FastBreak for excavation
4. NoFallDamage for safety
