# Aurora
https://aurora.nobleskye.com/

## Axiom-Style Creative Toolkit

Aurora is a creative utility mod inspired by Axiom, providing advanced building and creative mode tools with an intuitive toolbar interface.

## Features

### Core Functionality
- **Alt-Hold Toolbar**: Hold Left Alt to display the feature toolbar (inspired by Axiom)
- **Click to Toggle**: Click on toolbar buttons to enable/disable features
- **Real-time Status**: Visual indicators show which features are active
- **Tooltip System**: Hover over buttons to see feature names and status

### Builder Tools

- ✅ **Fast Place**: Place blocks without delay
  - Removes item use cooldown for rapid building
  - Toggle via toolbar or `/aurora toggle fastplace`

- ✅ **Fast Break**: Break blocks instantly
  - Instant block breaking for faster editing
  - Toggle via toolbar or `/aurora toggle fastbreak`

- ✅ **No Clip**: Phase through blocks
  - Walk through solid blocks and terrain
  - Toggle via toolbar or `/aurora toggle noclip`

- ✅ **Force Place**: Place blocks in occupied spaces
  - Override block placement restrictions
  - Toggle via toolbar or `/aurora toggle forceplace`

- ✅ **Replace Mode**: Replace blocks instead of placing new ones
  - Click blocks to replace them with held item
  - Toggle via toolbar or `/aurora toggle replace`

- ✅ **Tinker Mode**: Advanced block interaction
  - Right-click to copy block properties
  - Toggle via toolbar or `/aurora toggle tinker`

- ✅ **Freeze Updates**: Stop block updates
  - Prevents block state changes (water flow, etc.)
  - Toggle via toolbar or `/aurora toggle freezeupdates`

## Usage

### Toolbar Interface
1. **Hold Left Alt** to show the Aurora toolbar
2. **Click** on feature buttons to toggle them on/off
3. **Hover** over buttons to see feature names and status
4. **Release Alt** to hide the toolbar

### Command Interface
- `/aurora list` - Show all available features
- `/aurora status` - Show currently enabled features  
- `/aurora toggle <feature>` - Toggle a specific feature
- `/aurora enable <feature>` - Enable a specific feature
- `/aurora disable <feature>` - Disable a specific feature

### Legacy Keybinds
- `R` - Toggle Replace mode
- `L` - Toggle Tinker mode

## Installation

1. Install [Fabric Loader](https://fabricmc.net/use/)
2. Install [Fabric API](https://modrinth.com/mod/fabric-api)
3. Download Aurora and place in your mods folder
4. Launch Minecraft with the Fabric profile

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.16.9+
- Fabric API 0.119.2+
- Java 17+
