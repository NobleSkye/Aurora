## Early Beta Release

By installing Aurora, you agree to our [EULA](https://aurora.nobleskye.com/eula). Aurora is your all-in-one tool for enhancing and simplifying Minecraft editing, elevating your building potential to new heights.

## Features Checklist

Aurora offers an Axiom-inspired toolbar that appears when holding **Left Alt**. Click on toolbar buttons to toggle features:

### ✅ Core Features
- [x] **NoClip** - Walk through blocks freely
- [x] **Fast Place** - Place blocks instantly without delay
- [x] **Fast Break** - Break blocks instantly
- [x] **Force Place** - Force place blocks in any location
- [x] **Replace Mode** - Replace existing blocks while building
- [x] **Tinker Mode** - Advanced block manipulation tools
- [x] **Freeze Updates** - Prevent block updates and physics

### ✅ Interface Features
- [x] **Left Alt Toolbar** - Axiom-style horizontal toolbar
- [x] **Active Features Display** - Shows enabled features in top-left corner
- [x] **Click to Toggle** - Mouse click support for feature buttons
- [x] **Feature Descriptions** - Hover tooltips for each feature
- [x] **Visual Status Indicators** - Color-coded enabled/disabled states

### 🔧 How to Use

1. **Hold Left Alt** to display the Aurora toolbar
2. **Click on feature buttons** to toggle them on/off
3. **Hover over buttons** to see feature descriptions
4. **Active features** are shown in the top-left corner of your screen
5. Use **commands** `/aurora <feature>` for alternative control
