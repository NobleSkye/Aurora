# Aurora
https://aurora.nobleskye.com/

## Early Beta Release

By installing Aurora, you agree to our [EULA](https://aurora.nobleskye.com/eula). Aurora is your all-in-one tool for enhancing and simplifying Minecraft editing, elevating your building potential to new heights.

### Features

Aurora offers a focused set of creative utility tools designed for rapid block manipulation:

### Current Features (Toolbar Enabled)
- [x] FastPlace – remove item/block place cooldown
- [x] FastBreak – instant block destruction
- [x] NoClip – pass through blocks & fluid slowdown bypass
- [x] ForcePlace – override placement restrictions
- [x] Replace – destroy + place new block in one interaction
- [x] Tinker – cycle first block state property (empty hand swing)
- [x] FreezeUpdates – suppress block update propagation

### Planned / Ideas
- [ ] Flight speed adjuster
- [ ] Momentum / movement tweaking
- [ ] Display entity editor
- [ ] Dedicated settings screen (some mixins commented awaiting mappings)
- [ ] Quick update button / self‑version notifier

### Usage
Hold Left Alt to display the Aurora toolbar at the bottom of the screen. While holding:
- Press number keys 1–9 to toggle the corresponding feature (enabled entries show a * marker and green tint).
- Release Left Alt to hide the toolbar.

Enabled features also render in a compact list at the top-left.

### Commands
All features can also be managed with `/aurora`:
`/aurora list`, `/aurora status`, `/aurora toggle <name>`, `/aurora enable <name>`, `/aurora disable <name>`.

Names are lowercase (e.g. `fastplace`, `freezeupdates`).
